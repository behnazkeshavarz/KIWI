# KIWI — Google Keyword Collector

این افزونه هر بار که در گوگل جستجو می‌کنی، عبارات پیشنهادی بخش
«People also search for» و «جستجوهای مرتبط» پایین صفحه را به‌صورت
خودکار جمع‌آوری می‌کند، بدون تکرار به یک لیست اضافه می‌کند و امکان
خروجی گرفتن (TXT / CSV) یا کپی سریع را می‌دهد.

## نصب (Load Unpacked)

1. آدرس `chrome://extensions` را در کروم باز کن.
2. گزینه **Developer mode** (بالا-راست صفحه) را روشن کن.
3. روی دکمه **Load unpacked** بزن.
4. پوشه `keyword-collector` (همین پوشه‌ای که این فایل داخلشه) را انتخاب کن.
5. افزونه نصب می‌شود و آیکونش کنار نوار آدرس ظاهر می‌شود.

## استفاده

1. در گوگل هر عبارتی را سرچ کن (مثلاً «تلفن ابری»).
2. چند ثانیه صبر کن تا صفحه کامل لود شود — افزونه به‌صورت خودکار
   عبارات پیشنهادی را می‌خواند و ذخیره می‌کند (نیازی به کلیک نیست).
3. روی آیکون افزونه کلیک کن تا لیست جمع‌شده را ببینی. عدد روی آیکون
   نشان‌دهنده تعداد کل کلمات ذخیره‌شده است.
4. با نوار جستجوی داخل پاپ‌آپ می‌توانی لیست را فیلتر کنی.
5. با دکمه‌های پایین پاپ‌آپ می‌توانی: کل لیست را کپی کنی، خروجی TXT
   یا CSV بگیری، یا لیست را کامل پاک کنی.

## نکات فنی

- داده‌ها فقط در `chrome.storage.local` روی سیستم خودت ذخیره می‌شوند؛
  به هیچ سروری ارسال نمی‌شوند.
- افزونه فقط روی صفحات `google.com/search` فعال می‌شود.
- چون ساختار HTML گوگل گاهی تغییر می‌کند، اسکریپت از چند روش موازی
  برای پیدا کردن پیشنهادات استفاده می‌کند؛ اگر یک روز گوگل UI را
  عوض کرد و افزونه چیزی جمع نکرد، به من بگو تا سلکتورها را آپدیت کنم.
- کلماتی که خودت مستقیم سرچ کرده‌ای به لیست اضافه نمی‌شوند — فقط
  پیشنهادات مرتبط/تکمیلی گوگل جمع‌آوری می‌شود.

## فیچرهای فعلی

- گروه‌بندی خودکار کلمات زیر seed اصلی‌شون
- تشخیص intent (Transactional / Commercial / Navigational / Informational)
- ⭐ ستاره‌دار کردن کلمات مهم (بالای لیست میان)
- شمارش فراوانی (×N) — اگه یه کلمه زیر چند سرچ مختلف دیده بشه
- 📈 لینک مستقیم به Google Trends برای مقایسه محبوبیت نسبی کلمات
- دکمه روشن/خاموش کردن جمع‌آوری
- خروجی CSV/TXT با انکودینگ درست برای فارسی

## درباره حجم سرچ

هیچ API رسمی و رایگانی برای گرفتن عدد دقیق حجم سرچ وجود نداره — هر
ابزار «رایگانی» که عدد نشون می‌ده، یا پشت‌صحنه پولیه یا تخمینیه. برای
این‌که این ابزار همیشه ۱۰۰٪ رایگان بمونه، دکمه 📈 مستقیم به Google
Trends وصل می‌شه (رسمی، رایگان، بدون نیاز به اکانت) تا محبوبیت نسبی
کلمات رو با هم مقایسه کنی. اگه بعداً عدد دقیق خواستی، لیست ستاره‌دارها
رو می‌تونی توی Google Keyword Planner (رایگانه، فقط اکانت Google Ads
لازم داره، بدون نیاز به هزینه تبلیغاتی) وارد کنی.

## بعداً چه کار کنی با این لیست؟

خروجی CSV را می‌توانی مستقیم داخل Google Keyword Planner بریزی تا
حجم سرچ واقعی هرکدام را ببینی و اولویت‌بندی کنی.
